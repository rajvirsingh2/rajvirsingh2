## 🚀 Featured Projects

### 🎮 [Ascend — Gamified Personal Development RPG](https://github.com/rajvirsingh2)
`Kotlin` · `Jetpack Compose` · `Go` · `Chi` · `Redis Streams` · `PostgreSQL` · `HuggingFace Spaces` · `Docker`

- Architected a **Go (Chi) backend with Redis Streams** — quest completions return in **<15 ms** while XP calculation, achievement evaluation (16 types), and FCM push notifications run async on dedicated consumer workers.
- Deployed a custom **Phi-3 Mini (LoRA/QLoRA)** model on HuggingFace Spaces with Gradio SSE streaming; adaptive difficulty by completion rate, Redis-cached responses, DPO interaction tracking — **zero third-party API dependency**.
- Built an **offline-first Android client** (Kotlin/MVI + Hilt) securing every mutating call with **HMAC-SHA256 signing** and **JWT + refresh-token rotation**.

### 🛡️ Adaptive Deepfake Detection — Research @ ABV-IIITM
`Python` · `PyTorch` · `Continual Learning` · `UMAP` · `HDBSCAN`

- Built a framework tackling **catastrophic forgetting** in evolving deepfake threats via a **Continual Learning** paradigm.
- Engineered an **unsupervised UMAP + HDBSCAN pipeline** to auto-generate a sequence of learning tasks — simulating real-world threat evolution without manual labeling.
- Benchmarked **6 CL strategies**; **A-GEM reached 98.9%** in-domain accuracy with superior cross-domain generalization.

### 🧰 [Kotlin CLI — All-in-One Developer Toolkit](https://github.com/rajvirsingh2)
`Kotlin` · `Clikt` · `Docker` · `Gradle` · `Gemini API`

- Modular CLI centralizing dev workflows — filesystem manipulation, networking, and security tools — built on clean architecture.
- Engineered a custom **HTTP client**, a **polyglot code-snippet runner**, and a **persistent key-value store**, with unit tests throughout.
